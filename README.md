This is the GitHub repo for Quantifying microbial interactions based on compositional data using an iterative approach for solving Lotka-Volterra equations, 
submitted to PLOS Computational Biology.

If there are any questions about the code or data, please contact yhuang42@usc.edu OR fsun@usc.edu

Codes for Figures 1-5 are stored under the code folder.
Benchmarking codes and results are stored under benchmark folder.
Datasets used in the paper are stored under Data folder.
Figures 1-5 (tif plots) are stored under Fig folder.
